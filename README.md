# Voting App

Voting App is a real-time web application that allows users to create polls, cast votes instantly, and view live voting results without refreshing the page. The application is developed using Java Spring Boot and WebSocket technology to provide fast and seamless real-time communication between users and the server. It offers an interactive and responsive user experience with secure backend processing and efficient data handling. This project demonstrates the implementation of real-time features, client-server communication, and modern full-stack application development using Spring Boot.
## Features
- User voting
- Live vote updates
- Real-time communication
- Simple UI

## Technologies Used
- Java
- Spring Boot
- WebSocket
- HTML/CSS/JavaScript
